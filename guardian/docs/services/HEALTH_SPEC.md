# HEALTH — Спецификация сервиса (медицина / уход)

Сервис BOLH Super App: сиделки, медсёстры, врачи на дом, уход за пожилыми.

---

## Роли

| Роль | Описание |
|------|----------|
| **Заказчик / пациент** | Создаёт заявку на визит (тип услуги, адрес, дата/время, особенности здоровья). |
| **Специалист** | Сиделка, медсестра, врач: откликается на заявки, приезжает на дом, получает оплату. |

---

## Сущности

- **VisitRequest** — заявка на визит: заказчик, тип (caregiver / nurse / doctor), адрес, слоты, длительность, медицинские указания (конфиденциально), статус (open / assigned / in_progress / completed / cancelled).
- **VisitType** — тип визита: сиделка, медсестра (процедуры), врач (консультация/осмотр).
- **VisitOffer** — отклик специалиста: заявка, специалист, предложенная цена, комментарий, статус (pending / accepted / rejected).
- **Visit** — состоявшийся визит: заявка, специалист, время начала/окончания, результат (краткий отчёт при необходимости).

---

## API (основные операции)

- `POST /api/v1/health/requests` — создать заявку на визит (заказчик).
- `GET /api/v1/health/requests` — список заявок (фильтр по типу, региону, дате).
- `GET /api/v1/health/requests/:id` — детали заявки (медицинские данные только для участников).
- `POST /api/v1/health/requests/:id/offers` — специалист подаёт отклик.
- `POST /api/v1/health/offers/:id/accept` — заказчик принимает отклик.
- `POST /api/v1/health/visits/:id/start` — специалист отмечает начало визита.
- `POST /api/v1/health/visits/:id/complete` — завершение визита (оплата из кошелька).
- `GET /api/v1/health/my-requests`, `GET /api/v1/health/my-offers` — свои заявки и отклики.

---

## Интеграция с ядром BOLH

- **Аккаунт / профиль** — единый.
- **Кошелёк** — оплата визита, вывод специалисту.
- **Уведомления** — новый отклик, принятие, напоминания о визите.
- **Карта** — адрес визита (при необходимости геолокация для специалиста).

---

## Регуляторика и безопасность

- **Верификация специалистов** — дипломы, сертификаты, лицензии (по аналогии с Guardian). Обязательная модерация перед допуском.
- **Конфиденциальность** — медицинские данные только в рамках заявки/визита, соответствие GDPR и локальным нормам.
- **Страхование** — ответственность специалиста и платформы (legal/insurance.yaml).
- **Рейтинги** — оценка заказчика и специалиста после визита (без раскрытия мед. деталей).
