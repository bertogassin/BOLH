# HOME — Спецификация сервиса (услуги на дом)

Сервис BOLH Super App: клининг, ремонт, доставка, мастера на дом.

---

## Роли

| Роль | Описание |
|------|----------|
| **Заказчик** | Создаёт заявку (тип услуги, адрес, дата/время, описание). |
| **Мастер** | Откликается на заявки, выполняет работу, получает оплату. |

---

## Сущности

- **Request** — заявка: заказчик, категория (клининг / ремонт / доставка / другое), адрес, желаемые слоты, бюджет (опционально), статус (open / assigned / in_progress / completed / cancelled).
- **Category** — категория услуги: название, описание, типовые поля (площадь, тип ремонта и т.д.).
- **Offer** — отклик мастера: заявка, мастер, предложенная цена, комментарий, статус (pending / accepted / rejected).
- **Slot** — слот времени: дата, начало, конец (для выбора заказчиком и мастером).

---

## API (основные операции)

- `POST /api/v1/home/requests` — создать заявку (заказчик).
- `GET /api/v1/home/requests` — список заявок (фильтр по категории, региону, статусу).
- `GET /api/v1/home/requests/:id` — детали заявки.
- `POST /api/v1/home/requests/:id/offers` — мастер подаёт отклик с ценой.
- `POST /api/v1/home/offers/:id/accept` — заказчик принимает отклик (назначение мастера).
- `POST /api/v1/home/requests/:id/start` — мастер отмечает начало работы.
- `POST /api/v1/home/requests/:id/complete` — завершение (оплата из кошелька заказчика мастеру за вычетом комиссии).
- `GET /api/v1/home/my-requests`, `GET /api/v1/home/my-offers` — свои заявки и отклики.

---

## Интеграция с ядром BOLH

- **Аккаунт / профиль** — единый.
- **Кошелёк** — оплата заказа, вывод средств мастеру.
- **Уведомления** — новый отклик, принятие отклика, напоминания о слотах.
- **Карта** — адрес заявки, зона работы мастера (опционально).
