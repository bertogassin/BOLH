# WORK — Спецификация сервиса (бизнес-услуги)

Сервис BOLH Super App: курьеры, грузчики, переводчики, фриланс-задачи.

---

## Роли

| Роль | Описание |
|------|----------|
| **Заказчик** | Публикует задачу (тип: курьер / грузчики / перевод / иное), условия, бюджет, слоты. |
| **Исполнитель** | Откликается на задачи, выполняет, получает оплату. |

---

## Сущности

- **Task** — задача: заказчик, тип (courier / movers / translator / other), описание, откуда/куда (для курьера), дата/время, бюджет, статус (open / assigned / in_progress / completed / cancelled).
- **TaskResponse** — отклик исполнителя: задача, исполнитель, предложенная цена или «по договорённости», комментарий, статус (pending / accepted / rejected).
- **TaskType** — тип задачи: курьер (A→B), грузчики (адрес, объём), перевод (языки, формат), прочее.

---

## API (основные операции)

- `POST /api/v1/work/tasks` — создать задачу (заказчик).
- `GET /api/v1/work/tasks` — список задач (фильтр по типу, региону, дате).
- `GET /api/v1/work/tasks/:id` — детали задачи.
- `POST /api/v1/work/tasks/:id/respond` — исполнитель подаёт отклик.
- `POST /api/v1/work/responses/:id/accept` — заказчик принимает отклик.
- `POST /api/v1/work/tasks/:id/start` — исполнитель отмечает начало.
- `POST /api/v1/work/tasks/:id/complete` — завершение (оплата из кошелька).
- `GET /api/v1/work/my-tasks`, `GET /api/v1/work/my-responses` — свои задачи и отклики.

---

## Интеграция с ядром BOLH

- **Аккаунт / профиль** — единый.
- **Кошелёк** — оплата задачи, вывод исполнителю.
- **Уведомления** — новый отклик, принятие, напоминания.
- **Карта** — маршрут курьера, адреса грузчиков/переводчика.

---

## Рейтинги и верификация

- Оценка заказчика и исполнителя после выполнения.
- Верификация исполнителя по типу (права для курьера, документы переводчика и т.д.).
- SLA и штрафы (опционально): связь с operations/dispute_resolution.
