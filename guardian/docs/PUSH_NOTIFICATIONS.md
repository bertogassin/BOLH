# Типы push-уведомлений — Guardian

## Для клиента

| Тип | Иконка | Пример текста |
|-----|--------|----------------|
| Заказ создан | 🔵 | «Заказ #123 успешно создан» |
| Исполнитель найден | 🟡 | «Система подобрала охранника» |
| Заказ подтверждён | 🟢 | «Охранник Иван принял заказ» |
| Заказ отменён | 🔴 | «Исполнитель отказался от заказа» |
| Новое сообщение | 💬 | «У вас новое сообщение от охранника» |
| Завершён | ⭐ | «Заказ выполнен. Оцените работу» |

## Для охранника / агентства

| Тип | Иконка | Пример текста |
|-----|--------|----------------|
| Назначен заказ | 🔵 | «Вам назначен заказ #123» |
| Заказ принят клиентом | 🟢 | «Клиент подтвердил заказ» |
| Новое сообщение | 💬 | «Новое сообщение от клиента» |
| Напоминание | 📅 | «Заказ начнётся через 2 часа» |
| Выплата | 💰 | «Зачислено 5000 ₽ за заказ #123» |
| Статистика | 📊 | (по необходимости) |

## Реализация

- **iOS:** APNs, Firebase Cloud Messaging (FCM) или нативный APNs.
- **Android:** FCM.
- **Backend:** Notification Service подписан на Kafka-топики (match.created, match.accepted, order.completed и т.д.), формирует payload и отправляет в FCM/APNs.
- В приложениях: обработка данных уведомления (deep link на заказ/чат), бейдж на иконке «Уведомления».
