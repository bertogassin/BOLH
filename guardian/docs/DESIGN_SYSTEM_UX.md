# Guardian — дизайн-система и UX

## Бренд

- **Название:** GUARDIAN  
- **Слоган:** Надёжность. Скорость. Безопасность.

## Шрифты

## Атомы

- **Кнопки:** Primary (#0055FF, 56px), Secondary (обводка), Destructive (#FF3B30), Disabled opacity 0.5, тактильный отклик.
- **Поля ввода:** высота 56px, скругление 12px, обводка, состояние ошибки (красная обводка), показать/скрыть пароль.
- **Типографика:** H1 Bold 34px, H2 Bold 24px, H3 SemiBold 18px, Body Regular 16px, Caption 14px, Small 12px.

## Молекулы

- Карточка заказа: заголовок, дата/время, адрес, бейджи лицензий, кнопка «Подробнее».
- Карточка задания (Bid): имя, рейтинг, лицензии, график, действия.
- Tab Bar: Главная, Поиск, Заказы, Чаты, Профиль.

## Организмы

- Экран создания заказа: шаги (основное → лицензии → локация/время/бюджет → подтверждение), карта, счётчик охранников.
- Карта заказов: метки (синие — заказы, зелёные — исполнители), радиус поиска, кнопка «Моё местоположение», FAB «Новый заказ».

## Темы

- Светлая/тёмная по системной настройке (iOS: `@Environment(\.colorScheme)`, Android: `AppCompatDelegate.MODE_NIGHT_FOLLOW_SYSTEM`).
- Единые токены цветов через Theme (iOS: `Theme` struct, Android: `Material3Theme` + `ColorScheme`).

## Карты

- iOS: MapKit, Metal. Android: Google Maps / MapLibre, Vulkan.
- Стиль: метки заказов — синие, исполнителей — зелёные; радиус — полупрозрачный круг.

## Уведомления (Push)

- Клиент: заказ создан, исполнитель найден, заказ подтверждён/отменён, новое сообщение, заказ завершён (оценка).
- Охранник/агентство: назначен заказ, заказ принят, сообщение, напоминание (начало через N ч), выплата.
