# Guardian — веб-версия для клиентов

Не админка, а приложение для клиентов и охранников в браузере.

## Запуск

```bash
cd guardian/client-web
npm install   # один раз
npm run dev   # запуск на http://localhost:3003
```

Открой в браузере: **http://localhost:3003**

## Что есть

- **Главная** — приветствие, быстрые действия (Новый заказ, Мои заказы, Платежи, Чаты), активные заказы, плавающая кнопка «+», нижняя навигация.
- **Новый заказ** — заглушка (форма будет позже).
- **Заказы, Чаты, Профиль, Платежи, Уведомления** — заглушки с возвратом на главную.

Админ-панель: отдельный проект `guardian/admin` (порт 3000/3001).
