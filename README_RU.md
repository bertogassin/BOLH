# Guardio - Краткое руководство

## 🚀 Быстрый старт

Запустить всё приложение одной командой:

```bash
cd guardio-v2
pnpm run dev:all
```

Это запустит:
- **Мобильное приложение**: http://localhost:3000
- **Веб-приложение**: http://localhost:3001
- **Mock API сервер**: http://localhost:8080

## 🛠️ Полезные команды

```bash
# Остановить все серверы
Get-Process node | Stop-Process -Force

# Запустить всё заново
pnpm run dev:all

# Запустить только веб
pnpm run dev:web

# Запустить только мобильное
pnpm run dev:mobile

# Запустить только API
pnpm run api:mock

# Проверить порты
netstat -ano | Select-String ":3000|:3001|:8080"

# Тест API
Invoke-RestMethod -Uri http://localhost:8080/wallets
```
