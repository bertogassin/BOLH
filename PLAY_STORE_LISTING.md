## Play Console Upload Steps

1. Go to https://play.google.com/console
2. Create new app
3. Fill in store listing
4. Upload AAB file (`app-release.aab`)
5. Set content rating
6. Set pricing (Free)
7. Submit for review

**Review Time:** 1-7 days
