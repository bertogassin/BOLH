## Сценарий 1: Регистрация и вход

### Шаги (Client)
1. Открыть приложение
2. Нажать "Нет аккаунта? Зарегистрироваться"
3. Ввести:
   - Имя: Тест Клиент
   - Телефон: +79991111111
   - Пароль: test123
   - Роль: Клиент
4. Нажать "Зарегистрироваться"
5. **Ожидание:** Сообщение "Регистрация успешна"
6. Вернуться на экран логина
7. Ввести телефон и пароль
8. Нажать "Войти"
9. **Ожидание:** Переход на экран карты

### Шаги (Guard)
Повторить шаги 1-9, выбрав роль "Охранник"

---

## Сценарий 2: Создание заказа (Client)

### Предусловия
- Вошёл как Client
- Геолокация разрешена

### Шаги
1. Нажать кнопку "Создать заказ" (FAB)
2. Ввести:
   - Адрес: Москва, Красная площадь
   - Описание: Сопровождение на мероприятие
   - Цена: 5000
3. Нажать "Создать заказ"
4. **Ожидание:** Сообщение "Заказ создан!"
5. Заказ появился в списке со статусом "Новый"
6. Маркер заказа появился на карте (оранжевый)

### Проверки
- [ ] Координаты взяты из геолокации
- [ ] Статус = new
- [ ] Guard может видеть заказ (если в радиусе 5 км)

---

## Сценарий 3: Принятие заказа (Guard)

### Предусловия
- Вошёл как Guard
- Есть новый заказ в радиусе 5 км

### Шаги
1. Обновить список (кнопка refresh)
2. Увидеть заказ со статусом "Новый"
3. Нажать "Принять"
4. **Ожидание:** Сообщение "Заказ #N принят!"
5. Статус изменился на "Принят"
6. Появилась кнопка "Чат"

### Проверки
- [ ] Заказ исчез из списка новых для других охранников
- [ ] Client видит статус "Принят"

---

## Сценарий 4: Переписка в чате

### Предусловия
- Заказ в статусе "Принят"

### Шаги (Client)
1. Нажать "Чат" на карточке заказа
2. Ввести сообщение: "Привет! Где вы?"
3. Нажать отправить
4. **Ожидание:** Сообщение появилось справа (розовый пузырёк)

### Шаги (Guard)
1. Открыть чат того же заказа
2. **Ожидание:** Сообщение клиента появилось слева (серый пузырёк)
3. Ответить: "Уже выезжаю, буду через 10 минут"
4. **Ожидание:** Сообщение появилось справа

### Проверки
- [ ] Сообщения обновляются каждые 3 секунды (polling)
- [ ] Время отображается корректно

---

## Сценарий 5: Завершение заказа (Client)

### Предусловия
- Заказ в статусе "Принят"
- Вошёл как Client

### Шаги
1. Найти заказ в списке
2. Нажать "Завершить"
3. **Ожидание:** Сообщение "Заказ #N завершён!"
4. Статус изменился на "Завершён"
5. Кнопка "Завершить" исчезла

### Проверки
- [ ] Guard видит статус "Завершён"
- [ ] Чат остаётся доступным

---

## Сценарий 6: Проверка доступа (403)

### Guard пытается создать заказ
1. Войти как Guard
2. **Ожидание:** Кнопка "Создать заказ" отсутствует

### Client пытается принять заказ
1. Войти как Client
2. **Ожидание:** Кнопка "Принять" отсутствует на карточках

### Чужой Client пытается завершить заказ
1. Создать второго клиента (+79993333333)
2. Попытаться завершить заказ первого клиента через API
3. **Ожидание:** Ошибка 403 "Это не ваш заказ"

## Сценарий 7: Нет заказов рядом (Guard)

### Предусловия
- Вошёл как Guard
- Координаты далеко от всех заказов

### Шаги
1. Установить геолокацию в другом городе (через эмулятор)
2. Обновить список
3. **Ожидание:** "Нет заказов рядом"

## Сценарий 8: Ошибки сети

### Нет интернета
1. Отключить интернет на устройстве
2. Попытаться создать заказ
3. **Ожидание:** SnackBar "Ошибка сети"

### Backend недоступен
1. Остановить backend сервер
2. Попытаться войти
3. **Ожидание:** SnackBar с ошибкой
