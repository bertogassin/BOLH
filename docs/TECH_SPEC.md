# Guardio Rapidos - Техническое задание

## 1. Общее описание

**Guardio Rapidos** — платформа охраны по запросу с интегрированным маркетплейсом товаров безопасности и системой обучения.

### Целевая аудитория
- Клиенты, нуждающиеся в охране (личная, объект, мероприятие)
- Профессиональные охранники (исполнители)
- Покупатели товаров безопасности
- Ученики курсов по безопасности

---

## 2. Основные модули

### 2.1 Сервис охраны по запросу
- Заказ охранника по геолокации
- Отслеживание в реальном времени
- Система рейтингов и отзывов
- Разные типы услуг: личная охрана, сопровождение, охрана мероприятий

### 2.2 Маркетплейс
- Каталог товаров безопасности
- Категории: самозащита, видеонаблюдение, сигнализации, экипировка
- Корзина и оплата
- Доставка

### 2.3 Обучение
- Онлайн-курсы по безопасности
- Видео-уроки
- Тестирование и сертификация
- Прогресс обучения

### 2.4 Unity-симуляции (в перспективе)
- VR-тренажёры для охранников
- Симуляция экстренных ситуаций
- Интерактивное обучение

## 3. Технический стек

| Компонент | Технология |
|-----------|------------|
| Mobile App | Flutter |
| Web App | React + Vite + TypeScript |
| Backend API | Python + FastAPI |
| Database | PostgreSQL |
| Cache | Redis |
| Maps | Google Maps API |
| Auth | JWT |
| Payments | Stripe / YooKassa |
| Push | Firebase Cloud Messaging |

## 6. Требования к безопасности

- Все пароли хешируются (bcrypt)
- JWT токены с коротким временем жизни
- HTTPS обязателен
- Валидация всех входных данных
- Rate limiting
- Логирование действий
